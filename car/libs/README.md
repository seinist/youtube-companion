# Vendored Android Auto SDK (aauto)

`aauto.aar` is the unofficial OEM projection SDK originally reverse-engineered by
martoreto (`aauto-sdk`). Upstream was taken down at Google's request; JitPack is
unreliable.

This copy comes from [AndreyPavlenko/Fermata](https://github.com/AndreyPavlenko/Fermata)
(`fermata/lib/auto/aauto.aar`, AndroidX-patched). It enables `CarActivityService` /
`CarActivity` for custom projected UI beside the official media template.

Sideload / Unknown Sources only — not for Play Store distribution.
